# Student Expense Manager (Java Console Application)

A simple Java console application that allows students to record, view, and analyse their daily expenses.  
This project demonstrates core Java concepts such as:

- Classes and objects  
- Inheritance  
- Method overriding  
- ArrayList storage  
- Loops  
- Switch–case control  
- User input handling  

---

## 📂 Included Files

This repository contains the following Java source files:

Expense.java
DiscountedExpense.java
ExpenseManagerApp.java

These files together form the complete application.

---

## 🚀 Features

- Add normal expenses  
- Add discounted expenses  
- View all recorded expenses  
- Calculate total spending  
- Identify the highest expense  
- Menu loops until the user chooses to exit  

---

## 🛠️ How to Run

1. Download or clone the repository.
2. Open a terminal inside the folder containing the `.java` files.
3. Compile the program:
   ```bash
   javac *.java
4. Run the application:
java ExpenseManagerApp
